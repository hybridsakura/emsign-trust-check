TrustGuard 终端安全检测（Windows 便携版）
==========================================

运行要求
  - Windows 10（1607 及以上）或 Windows 11，64 位
  - 无需安装，无需 .NET 运行时（已内置），双击 TrustGuard.exe 即可
  - 建议右键「以管理员身份运行」：可多读取账户策略、BitLocker 等项
  - 标准权限运行时，右上角会显示「以管理员身份重启」，点击后 UAC 提权，
    当前窗口会自动关闭并由提权实例重新打开

程序功能
  选项卡一：emSign 证书漏洞
    - 系统吊销列表（Disallowed CTL）封锁状态
    - 本机证书存储中的问题证书（CA / ROOT）
    - 浏览器版本与封锁推送
    - 在线证书链探测（12 个测试站点，需要外网）

  选项卡二：终端场景风险
    - 使用场景可选：内网终端 / 外网终端 / 断网终端 / 自带设备（接入内网）
    - 只保留两项日常最关键的检查：
      · 官方安全补丁状态（系统支持期 + 最近一次更新的安装时间）
      · 防火墙开闭状态（域 / 专用 / 公用三个配置文件）
    - 每个危险等级标签后直接标注「待解决」或「无需操作」

界面说明
  - 绿色徽章 = 通过，红色 = 未通过，橙色 = 需关注，灰色 = 提示/未检测
  - 每项检查展开「查看影响与处置」可查看风险说明与修复方法
  - 右上角「导出报告」在桌面生成 HTML 报告，可直接交给安全管理部门汇总

命令行（供批量巡检/自动化使用）
  TrustGuard.exe --selftest --out C:\path\report.json
      无界面运行全部检查，结果写入 JSON；存在未通过项时退出码为 1
  TrustGuard.exe --tab2
      启动后直接定位到「终端场景风险」选项卡

隐私
  全部检测在本机完成，不联网上传任何数据；在线探测仅访问公开的测试域名。

分发说明
  scripts\Check-EmSignTrust.ps1  离线 Windows 批量检测脚本（可配合 -ExportCsv 汇总）
  scripts\fingerprints.json      16 张问题证书指纹（SHA-1 / SHA-256）
